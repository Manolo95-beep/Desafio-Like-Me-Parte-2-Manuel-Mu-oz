**Like Me | Desafío Node.js**

Desarrollo de una API REST para gestionar publicaciones y sus respectivos likes, aplicando conocimientos de desarrollo backend con **Node.js, Express y PostgreSQL**.

**Habilidades practicadas:**
- Creación y configuración de servidores con Node.js y Express.
- Implementación de rutas y endpoints REST.
- Manejo de peticiones HTTP (GET, POST, PUT).
- Conexión e interacción con bases de datos PostgreSQL.
- Ejecución de consultas SQL y operaciones CRUD.
- Uso de programación asíncrona con async/await.
- Manejo de errores y respuestas del servidor.
- Organización y modularización del código backend.
